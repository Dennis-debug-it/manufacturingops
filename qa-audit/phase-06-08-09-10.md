## Phase 6 — Preventive Maintenance
- PM Calendar renders (Month/Week, Overdue/Due-This-Week/Due-Soon/On-Track/Inactive buckets), `GET /api/preventive-maintenance` → 200. Tenant has 0 plans.
- Generation is **manual** (`POST /api/preventive-maintenance/{id}/generate-workorder`), permission-gated (Admin or `CanManageSettings`); advances `NextPmDate += interval` and copies the PM template checklist.

### F6-01 — LOW — No idempotency guard on PM work-order generation
- Double-submit (double-click / retry) creates **duplicate** PM work orders; no "open PM WO already exists for this cycle" check and no concurrency token. Same systemic no-optimistic-concurrency theme as F7-01.
- **Fix**: idempotency (dedupe by plan+cycle) or disable button while pending + server-side guard.

### F6-02 — LOW — PM scheduling uses UTC dates
- `seedDate = NextPmDate?.Date ?? DateTime.UtcNow.Date`; for an EAT (UTC+3) tenant this can produce off-by-one-day due dates near midnight. Consider tenant-timezone-aware date math.

## Phase 8 — Reports
- 6 report types (Work Order, SLA, PM Compliance, Finance, Technician Performance, CSAT), date-range filtered, all endpoints 200 and tenant-scoped. Correctly shows "no data" when WOs fall outside the window.

### F8-01 — MEDIUM — CSV injection + broken quote-escaping in report exports
- **Location**: `ReportsController` CSV builders (e.g. src/Ecosys.Api/Controllers/ReportsController.cs:124, 196, 290, 387).
- **Defect 1 (formula injection)**: cells are wrapped in quotes but leading `= + - @` are not neutralized. A client/asset/technician/title value like `=HYPERLINK("http://evil","click")` or `=cmd|'/c calc'!A1` executes when the CSV is opened in Excel/LibreOffice. Combined with F3-01 (no input validation) this is reachable by any tenant user who can name a record.
- **Defect 2 (CSV structure break)**: text is emitted as `\"{value}\"` **without doubling embedded `"`**. A value containing `"` (e.g. `foo","bar`) breaks the row into extra cells → data corruption / cell injection.
- **Fix**: escape embedded quotes (`value.Replace("\"","\"\"")`) and prefix a `'` (or space) to any cell starting with `= + - @ \t \r`.
